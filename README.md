# انبارشمار آفلاین آیفون

[بازکردن برنامه](https://anbarshomar-iphone-offline.onrender.com/)

برنامهٔ محلی شمارش انبار برای دو شرکت بسپار شیمی و سپید شیمی؛ ورود XLSX، جست‌وجوی تگ/کد/نام، سه نوبت شمارش، جمع ثبت‌ها، اصلاح ثبت، افزودن کالای خارج از فایل، خروجی اکسل و پشتیبان کامل.

## نصب روی آیفون

1. لینک را در Safari باز کنید و از Share گزینهٔ Add to Home Screen را بزنید. اگر Open as Web App دیده می‌شود روشنش کنید.
2. از آیکون صفحهٔ اصلی یک بار با اینترنت باز کنید و منتظر «آمادهٔ کار آفلاین» بمانید؛ سپس فایل خام را داخل همان نسخه وارد کنید.
3. برای خروجی، «ساخت خروجی اکسل» و سپس «ذخیره / اشتراک‌گذاری» را بزنید؛ در آیفون Save to Files و On My iPhone را انتخاب کنید.

هر نصب به یک انبار و دوره اختصاص دارد و داده‌ها میان گوشی‌ها همگام نمی‌شوند. پشتیبان و اکسل را در پایان هر نوبت جداگانه نگه دارید.

## ساخت و انتشار

- Render Static Site؛ پوشهٔ انتشار: `dist`
- فرمان ساخت: `python3 package-offline.py`
- فایل‌های لازم برای اجرای آفلاین با SHA-256 کنترل می‌شوند؛ انتشار ناقص فعال نمی‌شود.
- ساختار XLSX با ExcelJS حفظ می‌شود. مجوز کتابخانه‌ها و فونت در `dist/LICENSES.txt` است.

## وضعیت بررسی

انتشار HTTPS در ۲۰۲۶/۱۰/۳۱ موفق شد. آماده‌شدن واقعی کش آفلاین، ورود اکسل، ثبت شمارش و دریافت فایل خروجی در مرورگر Chromium بررسی شد. خروجی دانلودشده با openpyxl مستقل و کنترل CRC تمام اعضای ZIP تأیید شد: شمارش ۲، کد قالب‌بندی‌شدهٔ 00017، موجودی سیستم 12.5 و ریز ثبت‌ها درست بودند.

آزمون روی آیفون واقعی و Safari آیفون هنوز انجام نشده است؛ پیش از شمارش اصلی، فایل واقعی و ذخیره در Files را روی همان گوشی آزمایش کنید.
